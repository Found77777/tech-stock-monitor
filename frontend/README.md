# Tech Stock Monitor Frontend

Next.js App Router MVP for the A-share technology stock monitor.

## Start

```bash
npm install
npm run dev
```

API base URL defaults to `http://127.0.0.1:8000` and can be overridden with `NEXT_PUBLIC_API_BASE_URL`.

## Routes

- `/` Dashboard
- `/enhanced-watchlist`
- `/daily-review`
- `/trade-plan`
- `/trade-log`
- `/plan-drift`
- `/review-stats`
- `/ai-review-summary`
